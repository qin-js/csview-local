## 你正在看的是示例题库

这个公开站点部署在 GitHub Pages 上，**只托管界面代码**。

完整的 747 道题来自 [zijing2333/CSView](https://github.com/zijing2333/CSView)。该项目没有提供开源许可证，且作者在 README 中明确声明禁止转载与搬运，因此完整内容不会出现在这个公开站点上。

为了让你能立刻判断这套界面好不好用，这里内置了一份**由本项目作者原创撰写的示例题库**：10 个方向、15 篇分册、58 道题，涵盖三语言题解、表格、提示块、图示与题频统计。所有功能——折叠自测、掌握度标记、笔记、高频榜、全文搜索、自测循环、进度导出——在这份示例上都是真实可用的。

## 想看完整题库？

在本地跑三条命令，然后把产物导入这个页面即可，内容只存在你自己的浏览器里：

```bash
git clone https://github.com/qin-js/csview-local.git
cd csview-local
npm install && npm run fetch && npm run build
```

构建完成后点击顶部的题库来源按钮，选择 `public/` 目录导入。之后这个站点就是完整的 747 题版本，数据存在浏览器 IndexedDB 中，不上传任何服务器。

::: tip 为什么这样设计
「代码开源、内容自取」既尊重了原作者的声明，也让工具本身可以被任何人自由使用和改进。每位使用者直接从上游获取内容，不存在二次分发。
:::

## 这套界面做了什么

原站是文档站，适合读；这套界面把每道题变成可折叠、可自评、可记录的练习单元：

- **先想再看**：答案默认可以整篇折叠，逼自己先讲一遍
- **三档自评**：答得上来 / 有点模糊 / 还不会，直接写入掌握度，错题自动归集
- **题频排序**：把分散的题频记录归并成一张榜，时间有限时从上往下刷
- **自测循环**：随机 / 高频 / 错题 / 收藏 / 未学五种抽题，键盘全程可操作
- **本机存储**：进度、收藏、笔记、打卡全在浏览器里，可导出 JSON 备份

内容与题库策划的功劳属于 CSView 作者团队；本仓库只是重新设计了阅读与练习的方式。
